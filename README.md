# Airline Passenger Satisfaction — Classification

> Le Wagon Data Analytics bootcamp (2026)

## Business question
Which factors drive passenger satisfaction, and can we predict whether a passenger will be satisfied or dissatisfied?

## Data
Survey data on ~100K airline passengers: customer profile, travel class, flight distance, delays and ratings of each service (seat comfort, Wi-Fi, boarding, cleanliness…).

## Approach
1. Exploratory data analysis
2. Preprocessing: OneHotEncoder for categorical features, StandardScaler for numerical features
3. Baseline **Logistic Regression** vs. **Random Forest**
4. Evaluation with classification metrics
5. **Feature importance** to identify the service levers with the highest impact on satisfaction

## Stack
Python · pandas · scikit-learn · Jupyter
